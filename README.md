# 🚀 Featured Projects

## 1. 🏪 Central Superstore - SQL Data Warehouse & Business Analytics

[![View Repository](https://img.shields.io/badge/View%20Repository-GitHub-181717?style=for-the-badge\&logo=github)](https://github.com/Mostafa-Hassan-El-Sonbaty/Central_Superstore_SQL_Data_Warehouse)

Built an end-to-end **PostgreSQL Data Warehouse** from a raw retail dataset containing **2,323 order line items**.

Designed a **star-schema dimensional model** with a staging layer, fact table, and five dimensions. Built an ETL pipeline to transform raw transactional data into a structured analytical warehouse.

The analytical layer includes **18 SQL queries, CTEs, window functions, subqueries, CASE expressions, analytical views, a stored procedure, a table function, indexing, and EXPLAIN ANALYZE optimization**.

**Key Areas:**

* ⭐ Star Schema Data Warehouse
* 🔄 ETL & Data Transformation
* 🔗 Multi-table JOINs
* 📊 Advanced SQL Analytics
* 🪟 Window Functions
* 👁️ SQL Views
* ⚙️ Stored Procedures & Table Functions
* 🚀 Query Optimization

**Tech:** PostgreSQL · SQL · Data Warehousing · ETL · Advanced SQL · EXPLAIN ANALYZE
